| Prompts | `prompts/` — library, form, item, sidebar |
| Composables | File uploader, drag-and-drop, scroll, upload modal |
| Stores | `stores/files.ts`, `stores/prompts.ts` |
| E2E | Playwright flows for login, chatbot chat, feedback, file management |

## Tech stack

Vue 3, TypeScript, Pinia, Vitest/Jest-style unit tests, Playwright e2e
